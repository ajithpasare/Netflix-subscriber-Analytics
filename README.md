# Netflix-subscriber-Analytics
Netflix subscriber Churn Analysis Using Python and power BI
Netflix Subscriber Analytics 📊

📌 Project Overview

Netflix Subscriber Analytics is a Data Analytics project focused on analyzing subscriber behavior, customer churn patterns, and revenue trends.

The project uses Python for data cleaning and analysis and Power BI for data visualization.

🎯 Project Objectives

- Analyze Netflix subscriber data.
- Understand customer churn patterns.
- Identify factors associated with customer churn.
- Analyze subscription and customer behavior.
- Explore revenue trends across different regions.
- Present meaningful insights through data visualization.

🛠️ Tools & Technologies

- Python
- Google Colab
- Pandas
- Excel
- Microsoft Power BI

📂 Project Structure

- Screenshots: Power BI dashboard screenshots.
- Project XLS: Excel project file.
- Raw Data Set: Original dataset.
- IPYNB: Python analysis notebook.
- Documentation: Project documentation PDF.

📊 Key Insights

- Customer support interactions showed an association with customer churn.
- Customers with three support calls showed a churn rate of approximately 14% in the analyzed data.
- Most subscribers continued their subscriptions.
- Revenue remained relatively stable over the analyzed three-year period.
- Europe and North America contributed significantly to revenue.
